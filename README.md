# Número Secreto

**Descrição:**  
O projeto *Número Secreto* é um jogo simples em que o usuário tenta adivinhar um número gerado aleatoriamente. Utiliza comandos de voz como entrada.

**Tecnologias utilizadas:**
- HTML
- CSS
- JavaScript

**Boas práticas de código:**
- Estruturação clara e modular do código
- Utilização de boas práticas de nomenclatura
- Funcionalidade de feedback para o usuário
- Responsividade para diferentes dispositivos
